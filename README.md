# Tea & Coffee

Página web de Tea & Coffee, una cafetería de especialidad en Tarapoto.

Incluye inicio, carta, nosotros, galería y una ruleta de premios accesible mediante QR. Todo está integrado en un único archivo HTML.

## Sitio web

https://james-lian-nahui-bernabel.github.io/tea-coffee/

## Uso

Abre `index.html` en un navegador.
